# テスト結果

実行環境: IM920s Ver.01.21 × 2台 (IM920-USB 経由)、Ubuntu、2台は近距離 (RSSI 約 0xEB)

```bash
make hwtest A=/dev/ttyUSB0 B=/dev/ttyUSB1 N=300
```

## 結果: 152 項目すべて成功

### 単体テスト (ハードウェア不要、52項目)

| テスト | 内容 |
|---|---|
| `to_hex` / `parse_hex` | 16進数の変換、桁数・文字の不正を検出 |
| `parse_packet` | 正常な受信行、32バイト、全バイト値の往復 |
| `parse_packet` (異常系) | `OK` / `NG` / ID / バージョン / `RPRM` の応答 (コロン入り) / 桁不足 / 区切り違いなど 19 種類を受信行と誤判定しない |
| `Module` | 存在しないポート、シリアルポートでないファイルで例外 |

### その他のチェック

- AddressSanitizer / UndefinedBehaviorSanitizer: 問題なし
- `-Wall -Wextra -Wpedantic -Wshadow -Wconversion`: ライブラリ本体に警告なし

## テストで見つけて直したバグ

**タイムアウト後の応答の取り違え**

応答待ち時間を短く設定して `unicast` がタイムアウトすると、約6秒後に遅れて届いた `NG` を
次のコマンド (例: `id()`) の応答として返していた。
タイムアウトしたら、次のコマンドを送る前に遅れて来る応答を待って捨てるように修正。
